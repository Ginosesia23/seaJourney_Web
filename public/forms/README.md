# MCA Form PDFs

Place MCA PDF templates in this directory:

- `MSN_1858-Deckhand-Testimonial.pdf` - MCA Deckhand Testimonial form (MSN 1858)
- `MSN_1858-Officer-Testimonial.pdf` - MCA Officer Testimonial form (MSN 1858)
- `MSF_4371_Version_0126.pdf` - MCA Watch Rating form (if needed)
- `MSF_4274_Version_0626.pdf` - MCA CoC oral exam application (OOW / Chief Mate / Master)

The API routes will automatically serve these files if they exist in this directory.
